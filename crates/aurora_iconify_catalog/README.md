# aurora_iconify_catalog

Icon name lists for every [Iconify](https://iconify.design) icon set, plus the naming rules the `aurora_iconify` crates share.

This is an internal data crate. Depend on [`aurora_iconify`](https://crates.io/crates/aurora_iconify) instead. The lists are refreshed with `cargo run -p xtask -- iconify-catalog` and released with new versions.
